## CMIP7 Data Request Content

The information comprising the CMIP7 Harmonised Data Request, referred to as the **data request content**, is version controlled in this repository.
This is the DR for the CMIP7 Assessment Fast Track.

This repository is an appropriate place to [raise issues](https://github.com/CMIP-Data-Request/CMIP7_DReq_Content/issues) when errors or omissions are discovered in the data request.

Viewing the latest data request content is possible through these websites:
- [Airtable](https://bit.ly/CMIP7-DReq-latest)
- [Webviewer](https://cmip-data-request.github.io/cmip7-dreq-webview/latest)

For programmatic access, it is strongly recommended that users do not access the DR content directly from this repository.
The [data request python software](https://github.com/CMIP-Data-Request/CMIP7_DReq_Software) is provided for this purpose.

For further information about the latest DR release, please see the [CMIP7 website](https://wcrp-cmip.org/cmip7-data-request-latest).
